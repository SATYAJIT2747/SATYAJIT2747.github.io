About me

I build AI that you can measure and trust.

I'm an M.Tech CSE student at IIIT Hyderabad working on LLM agents, fine-tuning, RAG and MLOps. I like projects that have a real evaluation behind them: baselines, ablations and significance tests, not just demos.

My flagship project, Negotiate, Then Solve, pairs LLM agents with a CP-SAT constraint solver so the system only offers timetable changes the solver has verified. Our fine-tuned 4B model beats prompted Gemini on it.

I also like systems work. I wrote a BitTorrent-style file sharing system in C++17 with failover trackers, and I ship models end to end with DVC, MLflow, Docker, GitHub Actions and Kubernetes on AWS.
