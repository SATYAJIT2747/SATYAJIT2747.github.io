# Satyajit Priyadarshi · Portfolio

Live at **https://satyajit2747.github.io/**

A single-page portfolio (plain HTML/CSS/JS, no build step), hosted on GitHub Pages.

## Updating the resume
Replace `resume.pdf` with your new PDF (keep the same file name), then:

```bash
git add resume.pdf && git commit -m "Update resume" && git push
```

The site updates in about a minute. Every "Resume" button and the embedded preview use this file.
